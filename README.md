- **Phase 1 — Schema Design:** Designed and deployed the full Postgres schema (10 tenant-scoped tables: tenants, suppliers, contracts, contract_items, contract_chunks, purchase_orders, invoices, reconciliation_results, audit_log, agent_runs, llm_cache) with Row-Level Security enforced at the database layer. All natural-key uniqueness constraints are tenant-scoped. Diagnosed and fixed a false-pass in initial testing caused by Supabase's default `postgres` connection being a superuser that bypasses RLS; created a dedicated `app_user` role (`nobypassrls`) matching real application permissions. Verified genuine tenant isolation with a two-tenant insert/read test under those permissions.
